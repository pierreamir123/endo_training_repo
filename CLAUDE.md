## segmentation_model/

PRNet (from https://github.com/nkicsl/PRAD) trained on this repo's dataset (which **is**
the PRAD dataset). PRNet's `input_size` is baked into learnable params → **input must be
exactly 256×256**.

- `model.py` — vendored PRNet, `thop` import + broken `__main__` removed. Do not refactor.
- `networks/wtconv/` — `WTConv2d` vendored from BGU-CS-VIL/WTConv (PRAD repo omitted it).
- `dataset.py` — MONAI dict pipeline. Letterbox to 512 (longest side → 512, then pad —
  keeps aspect; dataset mixes 1600×1200 and 1200×1600) → random 256 crop + aug for train;
  full 512 for eval (sliding-window 256 at inference). Split (train/val/test) is read
  from `splits.txt`, generated by `make_splits.py` — deterministic 80/10/10 bucketed by
  **patient id** (`md5(A) % 10` on stem field A) so no patient leaks across splits.
  Run `make_splits.py` before training; run `dataset.py` directly for a self-check.
- `train.py` — `DiceFocalLoss` + AdamW/cosine + AMP, **W&B logging** (metrics only, no weight upload).
- `eval.py` — per-class Dice/IoU table + prediction/GT overlay PNGs, optional W&B.
- `wbutil.py` — loads `.env` (repo root) into env, then `wandb.init`.

**Weights:** each run gets `runs/<run-name>/{best,last}.pt` (+ `metrics.csv`); the best
+ last are also copied to `runs/{best,last}.pt` as the "latest" pointer. Run name is
`--name` or `prnet-<timestamp>`. `train.py` logs the best checkpoint to W&B as a model
artifact named after the run.

**W&B:** `.env` (gitignored) holds `WANDB_API_KEY` + `WANDB_PROJECT=prad-segmentation-model`
+ `WANDB_ENTITY=pierrebassily`. `--wandb online|offline|disabled` — train defaults
`online` (falls back to `offline` with no key), eval defaults `disabled`. This machine's
network drops large uploads; if an online run's final artifact sync fails, recover it
with `wandb sync wandb/offline-run-*` (or `wandb/run-*`).

Run via the wrappers (PowerShell) or `make`:

```
# PowerShell:
segmentation_model\setup.ps1
segmentation_model\train.ps1 --epochs 100 --name prnet-baseline
segmentation_model\eval.ps1 --save-overlays 6 --wandb online

# make (GNU make is in the endo env; run from Git Bash after `conda activate endo`):
make smoke
make train ARGS="--epochs 100 --name prnet-baseline"
make eval  ARGS="--save-overlays 6 --wandb online"
```

Wrappers pass extra args straight to the `.py`. `eval.ps1` defaults `--ckpt` to the
newest `runs/*/best.pt`.

**GPU/perf:** trains on CUDA automatically. Default `--batch-size 2` (~5 GB peak with
`DiceFocalLoss` on the 6 GB RTX 4050; `4` OOMs). `train.py` sets
`PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` on non-Windows to limit fragmentation.
`--cache disk` (default) uses `PersistentDataset` → `runs/<name>/cache/` (~21 GB, built
during epoch 1, then ~13 s/32 imgs). `--cache ram` needs ~20 GB free RAM (this box has
~6); `--cache none` reloads each epoch. Rough full-dataset cost: first epoch tens of
minutes to build cache, then ~25 min/epoch — start with `--epochs 30` or run overnight.

## Dataset

Semantic segmentation of **periapical** (intraoral) dental X-rays — close-ups of 2–4
teeth, NOT panoramic. This is the PRAD (Periapical Radiograph Analysis Dataset).

- `dataset/image/*.jpg` — 5000 X-ray images. Mixed sensor orientation: ~64% are
  1200×1600 (portrait), ~36% 1600×1200 (landscape). `dataset.py` letterboxes both.
- `dataset/label/*.png` — 5000 masks, **palette-indexed PNG** (open with PIL, `np.array` gives the class-index array directly — do not treat as RGB).
- Pairing is 1:1 by identical filename stem: `1-1-2.jpg` ↔ `1-1-2.png`. Stem format is `A-B-C` (patient-image-instance style), not a plain index.
- `dataset/label distribution.txt` — class map. Index 0 is background; foreground classes 1–9:

  1 Tooth · 2 Alveolar Bone (AB) · 3 Root Canal Filling (RCF) · 4 Denture Crown (DC) · 5 Implant (IM) · 6 Dental Fillings (DF) · 7 Pulp · 8 Orthodontic Devices (OD) · 9 Apical Periodontitis (AP)

- `.DS_Store` files are present in the dataset dirs — filter them out when listing.
